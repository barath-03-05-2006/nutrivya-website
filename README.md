# Nutrivya website

Intro website for the Nutrivya app (React + Vite).

## Run locally
```
npm install
npm run dev
```

## Build for production
```
npm run build
```
Output goes to `dist/`.

## Deploy on Vercel
Framework preset: **Vite** · Build command: `npm run build` · Output directory: `dist`

## Things to edit
- `src/data.js` – all the text (steps, features, audience) and the `DOWNLOAD_URL`
- `public/logo.png` – logo emblem shown next to the name (and used as the favicon)

## Hero image
Add a photo at `public/veg-bowl.jpg` to show it in the hero. Without it, a drawn vegetable bowl is shown.

## Contact details
Edit the `contact` object at the top of `src/data.js` (email, WhatsApp number, website, Instagram).
